## Description of the Repository
This repository contains a compilation of laboratory activities developed using the Laravel Framework and supporting design documentation. It demonstrates progress from exploration and UML design to Laravel application implementation, including Blade templating, CRUD operations, form validation, user authentication, and API integration.

## Application Development Activities

### Activity 1: Emerging Technologies Exploration
Short description: Emerging Technologies Exploration video project covering blockchain as a digital record stored in linked blocks. Once a block is added, it cannot be easily changed without everyone noticing, and multiple computers keep copies so the chain stays open and trustworthy.

### Activity 2: UML Diagram Design Project – Daily Grind Coffee Ordering System
Short description: The Daily Grind Coffee Ordering System is a digital platform designed to streamline operations between customers and shop staff. By replacing manual, verbal ordering with a structured digital interface, the system ensures accurate drink customization, real-time queue management, and automated inventory tracking. This integrated solution improves service speed and minimizes operational errors.

Location: `App Dev/Activity_2.docx`

### Activity 1: Project UML Final Project – Title & Design Proposal

It defines the system's functional boundaries, from menu navigation and order customization to inventory updates and payment processing.

Location: `SIA 2/Activity 1/Activity_Presentation_Final.docx`

### Activity 2: My Custom Info System (JJK Anime Characters List)
Short description: My Custom Info System is a Laravel web application built around a Jujutsu Kaisen theme. It uses an MVC structure to fetch character data from MySQL and display it in a responsive Blade interface, enabling users to explore a character list and view individual profiles.

Location: `SIA 2/Activity 2/jjk-project-list-act2`

### Activity 3: VibeTune Media Asset Manager
Short description: VibeTune Media Asset Manager implements full CRUD operations for digital audio records using Laravel and Eloquent ORM. It catalogs song details, artist profiles, genres, and release years while providing a dashboard interface for search, update, and media management.

Location: `SIA 2/Activity 3/vibetune_sys-act3`

### Activity 4: VibeCheck Listener Feedback System
Short description: VibeCheck Listener Feedback System is an analytics capture subsystem that securely processes and validates listener-submitted data. It emphasizes server-side validation, localized error feedback, and robust request handling to keep user telemetry accurate and responsive.

Location: `SIA 2/Activity 4/VibeCheck-Studio-act4`

### Activity 5: Secure Authentication Flow and Password Recovery
Short description: Secure Authentication Flow and Password Recovery focuses on building a complete Laravel authentication system with registration, login, and password recovery. It combines backend validation, session alerts, and dynamic UI elements to create a secure, user-friendly access control experience.

Location: `SIA 2/Activity 5/employee-dashboard-act5`
